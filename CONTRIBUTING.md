# Contributing to MetaGrid

Thank you for your interest in MetaGrid.

## Current Policy

- Bug reports are welcome through GitHub Issues.
- Feature requests are welcome through GitHub Issues.
- MetaGrid is currently **not accepting external code contributions or pull requests**.

## Issues

If you open an Issue, please focus on:

- What happened
- What you expected to happen
- Your MetaGrid version
- Your Windows version
- Any relevant logs with personal information removed

Please do not submit source-code patches, large diffs, or private data through Issues while external contributions are closed.

## Forks

MetaGrid may still be forked under the terms of the MPL-2.0 license. Opening an Issue does not transfer ownership of your ideas, code, or other materials.

## Pull Requests

Pull requests are not being accepted at this time. If that policy changes in the future, this document will be updated first.
