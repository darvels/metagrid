# MetaGrid v0.2.0

## Highlights

Auto Guides powered by Dota2ProTracker join MetaGrid's automatic High Winrate hero-grid updates.
Choose a hero and enable the Carry, Mid, Offlane, Support or Hard Support builds you want.

## Auto Guides

- Live D2PT Starting, Early, Core, Late and Situational items, skill builds and talents.
- Automatic synchronization for your selected Steam account.
- Disable a role to remove only its MetaGrid-owned guide; unrelated guides are preserved.
- Build availability changes over time: not every hero/role always has a D2PT build.

## Guide Accuracy

- Exact opening inventories and purchase quantities, including stacked items and Tango bundles.
- Talents selected by the highest D2PT Pick Rate.
- Validated item, ability and talent mappings without silent item drops.
- 218 Hero x Role builds available in the final pre-release D2PT audit.

## Reliability

- Verified Steam guide creation, readback, updates, removal and repeat synchronization without unnecessary writes.
- Preserved safe hero-grid merging, backup verification, restore/history and tray behavior.
- OpenDota MY BEST HEROES personalization and English/Russian UI remain available.
- Accumulated responsive Guides, hero-picker, status and startup fixes since v0.1.1.

## Download and Upgrade

Download **MetaGrid-v0.2.0-win-x64.zip**, verify it against the matching `.zip.sha256`,
extract the archive and run `MetaGrid.exe`. Windows 10/11 x64; no separate .NET runtime
installation is required. Microsoft Edge WebView2 Runtime, Steam and Dota 2 are required.

Users on v0.1.1 can update inside MetaGrid. Users on v0.1.0 should download the latest
ZIP manually once. External settings, account selection, subscriptions, caches, history
and backups are retained. Keep Steam running on the intended account when synchronizing guides.
