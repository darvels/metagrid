# MetaGrid v0.1.1

MetaGrid v0.1.1 adds built-in application updates, improves the interface, and strengthens update and install reliability.

## What's New

- Built-in MetaGrid application updater through GitHub Releases
- SHA-256 verification before application updates
- Safe external updater with staged replacement, path validation, and rollback
- Automatic application update checks with manual check support
- English and Russian interface support
- Improved Dashboard and update status UX
- Responsive and DPI-aware layout improvements

## Grid Improvements

- Optional MY BEST HEROES row using OpenDota statistics
- Uses the last 90 days
- Minimum 10 matches
- Minimum 53% win rate
- Up to 7 heroes
- Improved installed-grid detection and status accuracy

## Important for v0.1.0 Users

MetaGrid v0.1.0 does not include the new application updater.
Please download and install v0.1.1 manually once.
After v0.1.1 is installed, future compatible MetaGrid updates can be installed from inside the app.
